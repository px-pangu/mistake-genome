# 错题基因库 · 自适应错题本与薄弱点溯源

> 不是把错题抄一遍，而是回答三个问题：**为什么会错、前置知识点断在哪、下次什么时候再来找你**。

## 1. 这是什么

一个面向中学与大学低年级的**错题管理工具原型**。传统错题本的问题不是「没记下来」，而是：

1. **只抄不诊** —— 记了 300 道题，仍然不知道自己是概念不清还是审题偏差；
2. **复习节奏拍脑袋** —— 固定 1/2/4/7/15 天的艾宾浩斯表，对每个知识点一视同仁；
3. **溯源断在表面** —— 错题挂靠的知识点没错，真正的问题在它的**前置知识点**上。

错题基因库用六个模块把这三件事串起来，其中最核心的是第 03 模块：**用反应时 + 正确率动态估算记忆强度，据此推算下次复习间隔**。

### 当前版本的性质

- 单文件纯前端，`index.html` 双击即可运行，**不含任何外部网络请求**；
- 内置演示错题数据，用于呈现流程与算法效果；
- 设计清单中的拍照 OCR、LaTeX 公式识别、私有云同步属于**方案设计目标**，当前原型未接入；
- 当前版本**不使用 localStorage**，刷新即回到初始演示状态。

## 4. 功能模块详解

### 01 录入台（拍照 / 截图 / OCR）

- **用户动作**：拍照或截图 → 自动裁题 → 校对公式 → 打知识点标签 → 存入基因库。
- **核心逻辑**：版面切分题干 / 选项 / 作答区；公式转 LaTeX 并渲染对照，低置信字符高亮待校；**SimHash 查重**，命中时提示「已收录」并合并到原题。
- **关键字段**：`item_id`, `ocr_text`, `latex`, `confidence`, `subject`, `chapter`, `source`, `created_at`。
- **验收指标**：单题录入 P95 ≤ 15s；公式准确率 ≥ 95%（抽样 500 题）；低置信字符提示覆盖率 100%。

### 02 错因诊断卡

- **用户动作**：勾选错因 → 写一句自己的话 → 进入专属复习分支。
- **四分类分流**：

  | 错因 | 复习分支 |
  |---|---|
  | 概念不清 | 先补前置知识点，再做题 |
  | 计算失误 | 限时同类小题 3 道 |
  | 审题偏差 | 关键词圈画训练 |
  | 时间不足 | 拆步骤限时练 |

- **顽固基因机制**：同类错因连续 2 次 → 标记 `stubborn_flag`，自动提高基础题比例。
- **关键字段**：`error_type`, `self_note`, `branch_id`, `retry_count`, `stubborn_flag`, `resolved_at`。
- **验收指标**：四分类完成率 ≥ 90%；单题诊断 ≤ 20s；分支跳转正确率 100%。

### 03 每日回炉队列（自适应间隔）★ 核心

- **用户动作**：作答今日卡片 → 查看下次出现时间 → 需要时手动切回固定间隔。
- **算法**：以反应时 `RT` 与正确率估算记忆强度 `S`——

  | 作答表现 | 记忆强度 S 变化 |
  |---|---|
  | 答对且果断 | 大幅增加 |
  | 答对但犹豫 | 小幅增加 |
  | 答错 | 归零，并回插基础题 |

  下次间隔 `I = I₀ · e^(k·S)`，**钳制在 0.5–30 天**，并受「每日 ≤ 8 题」上限统一调度。
- **回滚开关**：保留「固定间隔 1/2/4/7/15 天」模式，切换时已排队列整体平移，**历史记录不丢失**。
- **关键字段**：`stability`, `last_RT`, `accuracy`, `next_due`, `interval_mode`, `rollback_log`。
- **验收指标**：自适应组 7 日重做正确率较固定组 + ≥ 8pp；日推送 ≤ 8 题达标率 100%；回滚后间隔序列与固定表一致率 100%。

### 04 知识点溯源树

- **用户动作**：点错题看挂靠知识点 → 展开前置链 → 一键生成「补基础」练习。
- **算法**：按错题密度算节点权重，定位**「前置断裂点」**（前置掌握度 < 60% 且自身错题 ≥ 2 次），可下钻到教材章节页码。
- **关键字段**：`kp_id`, `chapter`, `prereq[]`, `mastery`, `err_count`, `breakpoint_flag`, `textbook_page`。
- **验收指标**：溯源深度 ≥ 3 层；断裂点与人工标注一致率 ≥ 80%；节点展开 ≤ 1s。

### 05 薄弱基因图谱周报

- **用户动作**：周日打开 → 看热力变化 → 收 3 条建议 → 定下周重点。
- **算法**：知识点 × 周的热力矩阵，**暖橙深浅表示薄弱强度（不使用红色）**；只写变化——新增薄弱点、已转稳点、连续 3 周未变需换策略的点；自动生成下周 ≤ 3 个焦点知识点。
- **关键字段**：`week_id`, `heat_matrix`, `new_weak[]`, `stabilized[]`, `focus_next[]`。
- **验收指标**：周报生成 ≤ 3s；色阶零红色；焦点建议 ≤ 3 条。

### 06 数据与隐私中心

- **用户动作**：查看存储位置 → 导出或迁移 → 需要时删除。
- **逻辑**：本地加密存储 + 私有云端到端同步；导出 JSON / Markdown / CSV 与图片包；删除为软删，30 天后物理清除；同步冲突按时间戳 + 用户选择合并。
- **关键字段**：`storage_mode`, `sync_ts`, `export_format`, `delete_state`, `enc_key_id`。
- **验收指标**：导出 1000 题 ≤ 30s；30 天后物理清除率 100%；**第三方域名请求数 0**。

## 6. 硬约束（设计红线）

1. **无排名、无公开对比** —— 只呈现本人数据；
2. **连续使用 20 分钟强制休息**（未成年人同样适用），休息提示后锁屏 5 分钟；
3. **禁用「差生 / 学渣 / 逆袭」等标签化措辞**，统一用「还没掌握」替代「错误率高」；
4. **不展示他人姓名与成绩**，他人数据不可录入、不可导出；
5. **数据仅存本地与用户私有云**，默认不上传，无第三方分析 SDK，无排行榜接口。

> 未做完的复习**顺延，不做补偿式加量**——这是防沉迷设计的一部分。
