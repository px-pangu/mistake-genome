# 错题基因库 · 自适应错题本与薄弱点溯源 — 功能清单表

**全局基线**：单题录入 ≤ 15s；公式识别准确率 ≥ 95%；每日推送 ≤ 8 题；单次复习 ≤ 10 分钟；视觉为暖橙 #F2994A → 青灰 #6B7F8E 渐变，卡片留白 ≥ 24px，全站零红色告警。
**硬约束**：无排名、无公开对比；连续使用 20 分钟强制休息；禁用「差生 / 学渣 / 逆袭」等标签化措辞；不展示他人姓名与成绩；数据仅本地与用户私有云。
**迭代说明**：第 3 模块间隔由固定艾宾浩斯（1/2/4/7/15 天）改为「按反应时 + 正确率动态调整」，并保留手动回滚到固定间隔的开关。

---

### 01 录入台（拍照 / 截图 / OCR）

- **页面/模块**：录入台，支持拍照、截图、粘贴与批量拖入。
- **目标用户动作**：拍照或截图 → 自动裁题 → 校对公式 → 打知识点标签 → 存入基因库。
- **核心逻辑与算法**：版面切分题干 / 选项 / 作答区；公式转 LaTeX 并渲染对照，低置信字符高亮待校；SimHash 查重，命中提示「已收录」并合并到原题。
- **关键数据字段**：item_id, ocr_text, latex, confidence, subject, chapter, source, created_at。
- **防沉迷与伦理**：满 15 题或 12 分钟提示休息；默认本地与私有云存储；他人姓名、成绩不可录入。
- **可量化验收指标**：单题录入 P95 ≤ 15s；公式准确率 ≥ 95%（抽样 500 题）；低置信字符提示覆盖率 100%。

### 02 错因诊断卡

- **页面/模块**：错因诊断卡，四分类分流入口。
- **目标用户动作**：勾选错因 → 写一句自己的话 → 进入专属复习分支。
- **核心逻辑与算法**：概念不清→先补前置知识点再做题；计算失误→限时同类小题 3 道；审题偏差→关键词圈画训练；时间不足→拆步骤限时练。同类错因连续 2 次标记「顽固基因」，自动提高基础题比例。
- **关键数据字段**：error_type, self_note, branch_id, retry_count, stubborn_flag, resolved_at。
- **防沉迷与伦理**：措辞用「还没掌握」替代「错误率高」；无排名；单次批量标记 ≤ 20 题。
- **可量化验收指标**：四分类完成率 ≥ 90%；单题诊断 ≤ 20s；分支跳转正确率 100%。

### 03 每日回炉队列（自适应间隔）

- **页面/模块**：每日回炉队列，支持间隔模式切换。
- **目标用户动作**：作答今日卡片 → 查看下次出现时间 → 需要时手动切回固定间隔。
- **核心逻辑与算法**：以反应时 RT 与正确率估算记忆强度 S（答对且果断 S 大增；答对但犹豫小幅增；答错 S 归零并回插基础题），下次间隔 I = I₀ · e^(k·S)，钳制 0.5–30 天，受每日 ≤ 8 题上限调度；保留「固定间隔 1/2/4/7/15 天」开关，切换时已排队列整体平移，历史记录不丢。
- **关键数据字段**：stability, last_RT, accuracy, next_due, interval_mode, rollback_log。
- **防沉迷与伦理**：单次复习 ≤ 10 分钟；连续 20 分钟弹休息并锁屏 5 分钟；未做完顺延，不做补偿式加量。
- **可量化验收指标**：自适应组 7 日重做正确率较固定组 + ≥ 8pp；日推送 ≤ 8 题达标 100%；回滚后间隔序列与固定表一致率 100%。

### 04 知识点溯源树

- **页面/模块**：知识点溯源树，教材章节—知识点—前置知识点三层图。
- **目标用户动作**：点错题看挂靠知识点 → 展开前置链 → 一键生成「补基础」练习。
- **核心逻辑与算法**：按错题密度算节点权重，定位「前置断裂点」（前置掌握度 < 60% 且自身错题 ≥ 2 次），可下钻到教材章节页码。
- **关键数据字段**：kp_id, chapter, prereq[], mastery, err_count, breakpoint_flag, textbook_page。
- **防沉迷与伦理**：只呈现本人图谱，无班级 / 全校对比；图谱不导出他人数据。
- **可量化验收指标**：溯源深度 ≥ 3 层；断裂点与人工标注一致率 ≥ 80%；节点展开 ≤ 1s。

### 05 薄弱基因图谱周报

- **页面/模块**：周报热力图，知识点 × 周矩阵。
- **目标用户动作**：周日打开 → 看热力变化 → 收 3 条建议 → 定下周重点。
- **核心逻辑与算法**：暖橙深浅表示薄弱强度（不使用红色）；只写变化——新增薄弱点、已转稳点、连续 3 周未变需换策略的点；自动生成下周 ≤ 3 个焦点知识点。
- **关键数据字段**：week_id, heat_matrix, new_weak[], stabilized[], focus_next[]。
- **防沉迷与伦理**：禁用「退步 / 落后」等标签化措辞；不与任何人对比；周报仅本人可见。
- **可量化验收指标**：周报生成 ≤ 3s；色阶零红色（视觉检查）；焦点建议 ≤ 3 条。

### 06 数据与隐私中心

- **页面/模块**：数据中心，存储位置、导出迁移与删除。
- **目标用户动作**：查看存储位置 → 导出或迁移 → 需要时删除。
- **核心逻辑与算法**：本地加密存储 + 私有云端到端同步；导出 JSON / Markdown / CSV 与图片包；删除为软删，30 天后物理清除；同步冲突按时间戳 + 用户选择合并。
- **关键数据字段**：storage_mode, sync_ts, export_format, delete_state, enc_key_id。
- **防沉迷与伦理**：默认不上传、无第三方分析 SDK、无排行榜接口；未成年人连续 20 分钟强制休息。
- **可量化验收指标**：导出 1000 题 ≤ 30s；30 天后物理清除率 100%；第三方域名请求数 0。
